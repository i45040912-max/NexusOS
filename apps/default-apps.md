# NexusOS — приложения по умолчанию

Этот документ фиксирует желаемые приложения для будущей пользовательской среды NexusOS. Он не означает, что приложения уже включены в образ ОС или запускаются в текущем ядре.

## Список

1. **Visual Studio Code** — редактор кода.
2. **Yandex Music** — музыкальный сервис; вероятный первый вариант интеграции — веб-ярлык.
3. **Browser** — браузер по умолчанию; конкретный продукт ещё предстоит выбрать.
4. **Zen Browser** — альтернативный браузер, если поддерживается целевой пользовательской средой.

## Техническая реальность

NexusOS сейчас — freestanding x86-64 ядро. Для запуска этих приложений понадобятся как минимум:
- пользовательский режим и системные вызовы;
- память процессов и системные библиотеки;
- файловая система;
- графическая подсистема и оконный менеджер;
- сеть, TLS, аудио и необходимые мультимедийные компоненты;
- либо слой совместимости с Linux, либо отдельные нативные реализации приложений.

VS Code и Zen Browser не являются простыми переносимыми бинарниками для произвольного ядра. Yandex Music можно рассматривать как веб-приложение после появления браузера и сетевого стека.

## Предлагаемый первый практический шаг

Пока NexusOS разрабатывается, используйте отдельную Linux-среду как хост для разработки. Этот список станет спецификацией интеграции приложений, а не частью текущего загрузочного ISO.
