# ⚡ NEXUSOS — The Developer Operating System

> **NexusOS** — экспериментальная операционная система для разработчиков, создаваемая с нуля на C++.
>
> Цель проекта — исследовать устройство собственной ОС: от загрузки и управления памятью до пользовательских приложений и рабочего окружения для программирования.

## 🌌 О проекте

NexusOS — это стартовый open-source проект собственной операционной системы для x86-64. Репозиторий содержит начальный каркас ядра, загрузочную конфигурацию-заготовку, инструменты подготовки окружения и план развития проекта.

**Важно:** текущая версия — именно scaffold, а не готовая загрузочная ОС. Сборка загрузочного ISO, полноценный графический интерфейс, пользовательское пространство, сеть и запуск приложений ещё не реализованы.

## ✨ Планируемые возможности

- 🧠 **Собственное ядро на C++** — постепенная реализация базовых механизмов ОС.
- 💾 **Архитектура x86-64** — основная целевая платформа проекта.
- 🚀 **UEFI и загрузчик Limine** — предполагаемый путь загрузки системы.
- 🧵 **Управление памятью и задачами** — будущие подсистемы ядра.
- 🖥️ **Рабочее окружение для разработчиков** — интерфейс и инструменты для повседневной разработки в перспективе.
- 📦 **Каталог приложений по умолчанию** — проектирование интеграции привычных инструментов.
- 🧪 **QEMU** — планируемая среда для безопасного тестирования виртуальных сборок.

## 🧰 Приложения, которые планируется поддерживать

| Приложение | Планируемое назначение | Статус |
|---|---|---|
| Visual Studio Code | Редактор кода | В планах |
| Yandex Music | Музыка и фоновые плейлисты | В планах |
| Browser | Веб-браузер по умолчанию | В планах |
| Zen Browser | Альтернативный браузер | В планах |

Эти приложения **пока не входят в работающую систему**. Для их запуска потребуется пользовательское пространство, графическая подсистема, сеть и подходящий слой совместимости либо отдельные порты приложений. В частности, обычные приложения для Windows/Linux нельзя автоматически запускать в собственном ядре NexusOS.

Подробности: [`apps/default-apps.md`](apps/default-apps.md).

## 🛠️ Технологии

- **Языки:** C++ и немного C/assembly по мере необходимости
- **Архитектура:** x86-64
- **Стандарт C++:** ориентир на C++20
- **Загрузка:** UEFI + Limine — запланировано
- **Эмуляция:** QEMU
- **Сборка:** Make и GNU toolchain

Точный набор инструментов и конфигурация загрузчика будут уточняться по мере появления рабочего bootable-прототипа.

## 🚀 Начало работы

### Требования

Для подготовки среды разработки рекомендуется:

- Ubuntu или Debian Linux;
- `git`, `make`, компилятор C/C++ и binutils;
- `nasm`, `xorriso`;
- QEMU для будущего тестирования.

### Установка инструментов

Из корня репозитория выполните:

```bash
chmod +x tools/setup-ubuntu.sh
./tools/setup-ubuntu.sh
```

Скрипт предназначен для Ubuntu/Debian и устанавливает базовые инструменты разработки. Для сборки загрузочного образа могут понадобиться дополнительные зависимости после интеграции загрузчика.

### Посмотреть доступные команды

```bash
make help
```

**Обратите внимание:** на текущем этапе `make` не создаёт ISO-образ. Сначала нужно реализовать и проверить согласованный процесс сборки ядра и загрузочного образа.

```text
├── .gitignore
├── Makefile
└── README.md
```

Идеи, обсуждения и pull request приветствуются. Для крупных изменений сначала откройте issue и опишите:

1. какую проблему решает изменение;
2. что именно предлагается добавить;
3. как это можно проверить.

Поскольку проект находится на ранней стадии, перед отправкой изменений проверяйте, что README и документация не заявляют о функциях, которых ещё нет в коде.

## 📤 Публикация на GitHub

1. Создайте новый пустой репозиторий на GitHub, например `NexusOS`.
2. Распакуйте проект и откройте терминал в его корневой папке.
3. Выполните команды:

```bash
git init
git add .
git commit -m "docs: add NexusOS project scaffold"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/NexusOS.git
git push -u origin main
```

Замените `ВАШ-ЛОГИН` на свой GitHub username. Если репозиторий уже создан и подключён, повторно выполнять `git remote add origin` не нужно.
